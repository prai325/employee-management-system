Why do we create Base?

Remember Alembic?

target_metadata = Base.metadata

Base register all models.

Example->
    class User(Base):
    ...

    class Employee(Base):
        ...

Why do we use?
AsyncGenerator[AsyncSession, None]

Ans:
 Because get_db() uses yield instead of return, it becomes an async generator. It yields an AsyncSession object to FastAPI, and None indicates that no value is sent back into the generator.
